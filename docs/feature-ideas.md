# 추가 기능 제안

> 2026-11-20: 3·4·5·7·8·9·10·11·13·14·17·18번을 만들었습니다. 함께 "SSH 세션 시작 경로"(연결 시 경로 지정)도 넣었습니다.
> 1·2·6·12·15번은 이번에 하지 않았습니다(빠른 연결은 ⌘D/Alt+D 호스트 목록이 대신합니다).

지금 들어간 기능은 SSH/로컬 접속, 세션 저장(비밀번호·키·에이전트), 2·4분할, 라이트/다크, 암호화 보관함입니다.
아래 기능은 이 기능들을 매일 쓰다 보면 아쉬워질 지점을 채워 줍니다. 각 기능마다 어떤 상황에 쓸모 있는지를 함께 적었습니다.

우선순위 기준
- **높음**: 적게 만들어도 매일 체감하는 것
- **중간**: 특정 업무에서 크게 도움 되는 것
- **낮음**: 있으면 좋은 것

## 자세히

### 1. 빠른 연결 (`Ctrl+K`)
- 어디서든 `Ctrl+K`를 누르면 검색창이 뜨고, 세션 이름·호스트·그룹 일부만 쳐서 `Enter`로 바로 연결합니다.
- **이럴 때 좋아요**: 사이드바를 접고 전체 화면으로 쓰는 중에도 마우스 없이 새 서버를 열 수 있습니다. 세션이 수십 개일 때 특히 빠릅니다.

### 2. 자동 재연결
- 연결이 끊기면 창에 "다시 연결" 버튼을 띄우고, 설정하면 몇 초 뒤 알아서 다시 붙습니다.
- **이럴 때 좋아요**: 노트북 절전 뒤에 창 4개를 하나하나 다시 열 필요가 없습니다.

### 3. 서버 환경 색상 표시 — 완료
- 세션마다 색(운영=빨강, 스테이징=주황 등)을 정하면 탭과 창 테두리에 그 색이 보입니다.
- **이럴 때 좋아요**: 개발 서버라고 생각하고 운영 서버에서 `rm`이나 재시작을 치는 사고를 막아 줍니다.

### 4. 분할 창 동시 입력 — 완료
- 분할된 창 중 고른 창들에 같은 입력을 동시에 보냅니다. 켜져 있는 동안 창 테두리를 다르게 표시합니다.
- **이럴 때 좋아요**: 웹 서버 4대의 로그를 한 번에 `tail`하거나, 같은 패키지를 동시에 업데이트할 때 씁니다.

### 5. 터미널 안 검색 (`Ctrl+F`) — 완료
- 화면과 스크롤 기록에서 글자를 찾고, 찾은 곳을 강조해 위아래로 넘겨 봅니다.
- **이럴 때 좋아요**: 빌드나 배포 로그가 길게 지나간 뒤에 `ERROR` 줄만 찾아볼 때 씁니다.

### 6. 작업 공간 저장·복원
- 지금 열린 탭, 분할 모양, 창마다 붙은 세션을 이름 붙여 저장해 두고 한 번에 다시 엽니다.
- **이럴 때 좋아요**: "아침 점검"을 누르면 운영 서버 4대가 4분할로 한 번에 열립니다.

### 7. 점프 호스트 (ProxyJump) — 완료
- 세션에 "거쳐 갈 서버"를 지정하면 그 서버를 통해 목적지에 접속합니다. 인증은 각각 보관함에서 처리합니다.
- **이럴 때 좋아요**: 외부에서 배스천을 거쳐야만 들어갈 수 있는 사내망 서버에 한 번에 들어갑니다.

### 8. 포트 포워딩 — 완료
- 로컬 포워딩(`-L`), 원격 포워딩(`-R`), SOCKS 프록시(`-D`)를 세션에 저장해 두고, 연결할 때 함께 켭니다.
- **이럴 때 좋아요**: 내부망 MySQL에 내 PC의 DB 도구로 붙거나, 서버에서만 열리는 관리 페이지를 브라우저로 볼 때 씁니다.

### 9. 파일 주고받기 (SFTP) — 완료
- 창 옆에 원격 폴더 목록을 띄우고, 끌어다 놓아 올리고 더블클릭해 내려받습니다.
- **이럴 때 좋아요**: `scp` 명령을 따로 치지 않고 로그 파일을 받거나 설정 파일을 올립니다.

### 10. 명령 모음 (스니펫) — 완료
- 자주 쓰는 명령을 이름 붙여 저장하고, 메뉴나 `Ctrl+K`에서 골라 지금 창에 붙여 넣습니다. 보관함에 같이 저장하므로 다른 PC로도 따라갑니다.
- **이럴 때 좋아요**: `docker compose logs -f --tail=200 api` 같은 긴 명령을 매번 치지 않아도 됩니다.

### 11. 세션 기록 저장 — 완료
- 창의 출력을 시간과 함께 파일로 남깁니다. 세션별로 켜고 끌 수 있습니다.
- **이럴 때 좋아요**: 장애 대응 때 무엇을 했는지 나중에 보고서로 정리하거나, 작업 내역을 남겨야 할 때 씁니다.

### 12. `~/.ssh/config` 가져오기
- 기존 SSH 설정 파일을 읽어서 `Host`마다 세션을 만들어 줍니다. 호스트, 포트, 사용자, 키 파일, ProxyJump를 가져옵니다.
- **이럴 때 좋아요**: 이미 터미널에서 쓰던 서버 수십 대를 한 번에 옮겨 옵니다.

### 13. 자동 잠금 + 이 PC에서 기억하기 — 완료
- 일정 시간 아무 입력이 없으면 보관함을 잠급니다. "이 PC에서 기억하기"를 켜면 마스터 비밀번호 대신 OS 키체인(Windows 자격 증명 관리자, macOS 키체인)으로 엽니다.
- **이럴 때 좋아요**: 자리를 비워도 안전하고, 내 PC에서는 매번 비밀번호를 칠 필요가 없습니다.

### 14. 분할 경계 드래그 — 완료
- 분할된 창 사이 경계를 끌어서 크기를 바꾸고, 더블클릭하면 반반으로 돌아갑니다.
- **이럴 때 좋아요**: 왼쪽에서 편집기를 넓게 쓰고 오른쪽은 좁게 로그만 볼 때 씁니다.

### 15. OTP·2단계 인증 (keyboard-interactive)
- 서버가 묻는 질문(비밀번호, OTP 번호)을 터미널 안에서 차례로 받아 답합니다.
- **이럴 때 좋아요**: 회사 보안 정책으로 OTP를 쓰는 서버에도 접속할 수 있습니다. 지금은 이런 서버에 접속하지 못합니다.

### 16. 설정 화면 — 완료
- 터미널 글꼴과 크기, 스크롤 기록 길이, 닫기 확인 켜기·끄기, 단축키 목록을 한곳에서 봅니다.
- **이럴 때 좋아요**: 닫기 확인에서 "다시 묻지 않음"을 골랐다가 다시 켜고 싶을 때 이 화면이 필요합니다. 지금은 되돌리는 화면이 없습니다.

### 17. 세션 복제 — 완료
- 세션 편집 화면에서 "복제"를 누르면 같은 설정으로 새 세션이 만들어지고, 호스트만 바꿔 저장합니다.
- **이럴 때 좋아요**: `web-01`부터 `web-08`까지 사용자와 키가 같은 서버를 빠르게 등록합니다.

### 18. 연결 상태 표시 — 완료
- 창 머리에 응답 시간(ms)을 작게 보여 주고, 끊기면 바로 표시합니다.
- **이럴 때 좋아요**: 명령이 느릴 때 서버 문제인지 네트워크 문제인지 바로 알 수 있습니다.

## 추천 순서

1. **먼저 1~5번.** 작업량이 작고 매일 체감합니다. 특히 3번 색상 표시와 4번 동시 입력은 분할 기능과 잘 맞습니다.
2. **다음 6번과 14번.** 분할 화면을 자주 쓰신다면 이 둘이 쓰는 경험을 가장 많이 바꿉니다.
3. **그다음 7·8·12번.** 사내망이나 배스천을 쓰는 환경이라면 이 셋을 앞당기는 게 좋습니다.
