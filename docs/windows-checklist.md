# Windows 점검표

1.0 전에 Windows 실기기에서 한 번 손으로 확인할 것. 릴리스의 `SSHBook_x.y.z_x64-setup.exe`로 설치해서 본다.
결과는 칸에 ✓ / ✗ 와 메모로 적는다. ✗가 하나라도 있으면 이슈로 남기고 고친 뒤 다시 확인한다.

## 설치와 업데이트
- [ ] 설치 파일 실행 → "Windows의 PC 보호"에서 추가 정보 → 실행으로 설치된다
- [ ] 이전 버전이 설치된 상태에서 앱 안 업데이트(설정 → 업데이트 확인 → 지금 업데이트)가 끝나고 새 버전으로 다시 켜진다

## 보관함
- [ ] 보관함 만들기, 잠그기, 잠금 해제, 비밀번호 바꾸기
- [ ] 내보내기 → 다른 경로로 가져오기
- [ ] 백업에서 되돌리기(잠금 화면)
- [ ] `%APPDATA%\com.moning02004.sshbook`에 `vault.sshv`, `backups\`, `logs\`가 생긴다

## 터미널
- [ ] 로컬 셸(PowerShell)에서 한글 입력·출력, 붙여넣기
- [ ] SSH 비밀번호·키·에이전트("OpenSSH Authentication Agent" 서비스 켠 상태) 접속
- [ ] 점프 호스트, 시작 경로, -L 포워딩(브라우저로 127.0.0.1:포트 열기)
- [ ] 끊긴 탭에서 `Ctrl+R` 다시 연결, 연결된 셸에서는 `Ctrl+R`이 기록 검색으로 간다
- [ ] `Ctrl+D`가 셸로 간다(로그아웃), `Ctrl+F`가 셸로 간다
- [ ] 연결 중, 비밀번호·호스트 키 입력 중에 `Esc`로 취소된다
- [ ] 여러 줄을 붙여 넣으면 먼저 묻고, 취소하면 아무것도 입력되지 않는다
- [ ] 바뀐 서버 키는 지문 앞 8글자를 직접 쳐야 수락된다
- [ ] OTP를 묻는 서버(또는 keyboard-interactive 서버)에 코드를 입력해 접속된다

## 단축키
- [ ] `Alt+D` 호스트 목록, `Alt+1`~`Alt+9` 탭 이동, `Ctrl+Tab` / `Ctrl+Shift+Tab`
- [ ] `Ctrl+Alt+방향키` 칸 이동(그래픽 드라이버의 화면 회전 단축키와 겹치지 않는지)
- [ ] `Ctrl+Shift+F` 찾기, `Ctrl+Shift+S` 명령 모음, `Ctrl+Shift+O` 파일 창, `Ctrl+Shift+W` 탭 닫기
- [ ] `Ctrl+,` 설정, `Ctrl+=`/`-`/`0` 글자 크기, `F11` 전체 화면

## 화면
- [ ] 탭을 끌어 다른 칸 탭 줄·가장자리·가운데로 옮기기, 경계 끌어서 크기 조절
- [ ] 탭 더블클릭으로 이름 바꾸기, 그룹 이름 바꾸기
- [ ] 앱을 끄고 다시 켜면 확인 창 없이 지난번 탭과 분할이 끊긴 상태로 보이고, `Ctrl+R`을 누른 탭만 연결된다
- [ ] 세션 편집 창에서 머리글과 저장 버튼은 고정되고 본문만 스크롤된다

## 가져오기와 언어
- [ ] 설정 → 가져오기에서 `%USERPROFILE%\.ssh\config`의 호스트를 세션으로 만든다
- [ ] 설정 → 화면에서 English를 고르고 앱을 다시 켜면 영어로 보이고, 한국어로 되돌릴 수 있다

## 파일 창 (SFTP)
- [ ] 터미널의 지금 폴더에서 열린다
- [ ] 탐색기에서 파일·폴더를 끌어다 놓아 올리기(진행률, 취소)
- [ ] 폴더째 내려받기, 한글 파일 이름
- [ ] 이미 있는 폴더로 내려받으면 덮어쓸지 묻는다
- [ ] 서버의 `C:evil`, `CON`, `a.` 같은 이름은 건너뛰고 고른 폴더 밖에 아무것도 생기지 않는다
